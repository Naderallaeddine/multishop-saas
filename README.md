# MultiShop SaaS

A multi-tenant SaaS e-commerce platform built with .NET 8 and React.

## Tech Stack
- **Backend:** ASP.NET Core 8, Clean Architecture, Entity Framework Core, JWT Auth
- **Frontend:** React 18, TypeScript, Tailwind CSS
- **Real-time:** SignalR
- **Database:** SQL Server, Redis
- **DevOps:** Docker, Azure, GitHub Actions CI/CD

## Architecture
Multi-tenant platform where businesses can create and manage their own online store.

## Status
In active development.
